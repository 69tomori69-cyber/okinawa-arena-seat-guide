# 仮の値の一覧

設計書の「確認が必要なこと」がまだ決まっていないため、次の値は**仮**で入れています。
データは `data/venue-data.js` にあり、仮のものには `tentative: true` が付いています。
確認できたら値を直し、`tentative: true` を消してください。画面の「仮」の表示も自動で消えます。

| 項目 | いまの仮の値 | 何で確かめるか | データの場所 |
| --- | --- | --- | --- |
| 各ゲートの階 | 下段ゲート（A21〜G21）は2階、上段ゲート（A41〜G41）は4階（図面の壁の出入口と座席図のゲートが一致） | 現地 | `floors` |
| 図面と座席図の重ね合わせ | 柱4本の位置で合わせた（ずれは1ピクセル以内）。ブロック番号の位置は座席図から移したもの | — | `blocks` の `pos` |
| コンコース（客席の外の廊下）の通り道 | 2F・4Fの図面の廊下に沿って一周。ロビーは吹抜けを避けて通る | 現地 | `nodes` の `L-…` `U-…` |
| 階段・エレベーター | 位置は図面のもの（階段6〜9、EV1〜5）。どれも2階と4階を結ぶと仮定 | 現地（一般のお客さまが使えるか） | `nodes` の `st…` `ev…`、`edges` |
| 入場口（チケットを見せる所） | 未登録（ゲートと階段にだけQRを置く想定） | フロアマップ・現地 | `nodes` に追加 |
| ゲートを入った所の横通路の位置 | 下段は11列と12列の間、上段は4列と5列の間 | 現地 | `blocks` の `aisleAfterRow` |
| 列の範囲 | 座席図の列番号から読み取り（斜めのブロックや東側は推定） | 座席図の拡大・現地 | `blocks` の `rows` |
| 席番号（番）の範囲と並ぶ向き | 範囲は 1〜600 まで入力可、向きは未設定 | 座席図の拡大・現地 | `maxSeatNumber` |
| チケットの座席表記 | 「ブロック・列・番」の3つと仮定 | 実際のチケット | 画面の入力欄 |
| 緑の区画（301〜330） | ボックス席として、近くのゲートまで案内 | 施設・主催者 | `blocks`（group: box） |
| ピンクの区画（T1〜T3） | **未登録**（選べません） | 施設・主催者 | `blocks` に追加 |
| 1階コートサイド（1〜10・KGB・AWB・Hollywood・Broadway） | サウスエントランス＝1階の左下の「エントランス(1-1)」と仮定。ロビーの奥からアリーナフロア入口へ向かう道は図面からの推定。席の位置はセクション区分けの図から移したもの | 施設・主催者 | `nodes` の `gate-south` `G-…` `gate-floor`、`blocks`（group: court） |
| 111〜116 | セクション区分けの図から位置を移し、ゲート割どおり111〜113はB21、114〜116はB22。列・番は未設定 | 座席図・現地 | `blocks`（group: front） |
| 201A〜208A の区画 | セクション区分けの図から位置を移し、ゲート割どおり201〜204はG21、205〜208はA21 | 座席図・現地 | `blocks`（group: sub） |
| パノラマラウンジ（500〜514） | 5階ロビー。A41・G41ゲートを入り、すぐ横の階段11・12で5階へ上がる（500・514も同じ扱い） | 施設・主催者 | `nodes` の `lounge` `st11` `st12` |
| 401〜407の入口 | ゲート割の図にゲートがないため、図面で客席のすぐ後ろにある4階ロビーから入ると仮定 | 施設・主催者 | `nodes` の `gate-lobby4-…` |
| 各ブロックの入場ゲート | いただいたゲート割の図と一致することを確認済み | — | `blocks` の `gate` |
| 距離の縮尺 | 平面図1ピクセル＝0.0915m（コートの長さ28mから計算） | 実測 | `metersPerPixel` |
| QRコードの設置場所 | 各ゲート横、階段・エレベーターの乗り口、4階ロビー、サウスエントランスの40か所 | 施設・主催者の許可 | `qrCodes` |
