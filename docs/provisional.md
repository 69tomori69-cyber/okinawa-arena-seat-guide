# 仮の値の一覧

設計書の「確認が必要なこと」がまだ決まっていないため、次の値は**仮**で入れています。
データは `data/venue-data.js` にあり、仮のものには `tentative: true` が付いています。
確認できたら値を直し、`tentative: true` を消してください。画面の「仮」の表示も自動で消えます。

| 項目 | いまの仮の値 | 何で確かめるか | データの場所 |
| --- | --- | --- | --- |
| 各ゲートの階 | 下段ゲート（A21〜G21）は2階、上段ゲート（A41〜G41）は4階 | 施設のフロアマップ | `floors` |
| コンコース（客席の外の廊下）の形 | 下段は座席図の紺色の八角形の線、上段は上段ゲートの並びに沿って一周 | フロアマップ・現地 | `nodes` の `L-…` `U-…` |
| 階段・エレベーターの場所 | 座席図の四隅にある紺色の四角を階段と仮定。エレベーターは北東と南西だけ | フロアマップ・現地 | `nodes` の `core-…`、`edges` |
| 入場口（チケットを見せる所） | 未登録（ゲートと階段にだけQRを置く想定） | フロアマップ・現地 | `nodes` に追加 |
| どのブロックがどのゲートを使うか | 座席図で一番近いゲート | 現地・施設 | `blocks` の `gate` |
| ゲートを入った所の横通路の位置 | 下段は11列と12列の間、上段は4列と5列の間 | 現地 | `blocks` の `aisleAfterRow` |
| 列の範囲 | 座席図の列番号から読み取り（斜めのブロックや東側は推定） | 座席図の拡大・現地 | `blocks` の `rows` |
| 席番号（番）の範囲と並ぶ向き | 範囲は 1〜600 まで入力可、向きは未設定 | 座席図の拡大・現地 | `maxSeatNumber` |
| チケットの座席表記 | 「ブロック・列・番」の3つと仮定 | 実際のチケット | 画面の入力欄 |
| 緑の区画（301〜330） | ボックス席として、近くのゲートまで案内 | 施設・主催者 | `blocks`（group: box） |
| ピンクの区画（T1〜T3）、コートサイド席 | **未登録**（選べません） | 施設・主催者 | `blocks` に追加 |
| パノラマラウンジ（500〜514） | 2Fの東側にあるため、下段コンコース東側の「ラウンジ入口（仮）」まで案内 | 施設・主催者 | `nodes` の `lounge` |
| 距離の縮尺 | 座席図1ピクセル＝0.06m | 実測 | `metersPerPixel` |
| QRコードの設置場所 | 各ゲート横、階段の乗り口、ラウンジ入口の30か所 | 施設・主催者の許可 | `qrCodes` |
| 公開先のURL | GitHub PagesのURL（独自ドメインは未定） | 運営判断 | qr.html で印刷前に書き換え |
