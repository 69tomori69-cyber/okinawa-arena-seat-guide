# 仮の値の一覧

設計書の「確認が必要なこと」がまだ決まっていないため、次の値は**仮**で入れています。
データは `data/venue-data.js` にあり、仮のものには `tentative: true` が付いています。
確認できたら値を直し、`tentative: true` を消してください。画面の「仮」の表示も自動で消えます。

| 項目 | いまの仮の値 | 何で確かめるか | データの場所 |
| --- | --- | --- | --- |
| 各ゲートの階 | 下段ゲート（A21〜G21）は2階、上段ゲート（A41〜G41）は4階（図面の壁の出入口と座席図のゲートが一致） | 現地 | `floors` |
| 図面と座席図の重ね合わせ | 柱4本の位置で合わせた（ずれは1ピクセル以内）。ブロック番号の位置は座席図から移したもの | — | `blocks` の `pos` |
| コンコース（客席の外の廊下）の通り道 | 2F・4Fの図面の廊下に沿って一周。ロビーは吹抜けを避けて通る | 現地 | `nodes` の `L-…` `U-…` |
| 階段・エレベーター | 位置は図面のもの（階段6〜9、EV1〜5）。どれも2階と4階を結ぶと仮定 （地図のアイコン・現在地の選択肢・QRからは削除し、階の移動にだけ使う） | 現地（一般のお客さまが使えるか） | `nodes` の `st…` `ev…`、`edges` |
