# 平面図の作り方

`assets/floors/2f.webp`・`4f.webp` は、施設の図面（各階平面図の画像）から次の手順で作っています。
図面の画像はリポジトリに入れていません。作り直すときは図面の画像を `p2.png`（2F）・`p4.png`（4F）として置いてください。

1. `reg.py`：座席図PDFと図面を、柱4本の位置で重ねる計算（2Fの図面は柱が75ピクセル上に描かれているので、下にずらして3F〜5Fと同じ位置にそろえる）
2. `polys.py`：建物の外形・客席の範囲・コートの位置（図面上の座標）
3. `render.py`：図面を塗り分ける（線が密集している所＝客席を紺、コートを木の色、床をグレー、外側は透明）
4. `nodes.py`・`gen.py`：ゲート・廊下・階段・エレベーターの位置を図面から読み取り、`data/venue-data.js` に書き出す

必要なもの：Python 3、opencv-python-headless、numpy、Pillow
